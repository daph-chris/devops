Exercise 4 – Jenkins Pipeline Using Docker
Tools: Docker, Docker Compose, Jenkins, HTML, CSS, HTML Publisher Plugin.

Step 1: Create project folder
Open PowerShell:

mkdir jenkins-static-site
cd jenkins-static-site
Step 2: Create docker-compose.yml
notepad docker-compose.yml
Paste:


services:
  jenkins:
    image: jenkins/jenkins:lts
    container_name: jenkins
    restart: unless-stopped
    ports:
      - "8080:8080"
      - "50000:50000"
    volumes:
      - jenkins_home:/var/jenkins_home

volumes:
  jenkins_home:
    driver: local
Save and close.

Step 3: Start Jenkins
docker compose up -d
Check container:

docker ps
Step 4: Get Initial Admin Password
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
Copy the password.

Open browser:

http://localhost:8080
Enter the password.

Click Install suggested plugins.

Create an admin user.

Finish setup.

Step 5: Install HTML Publisher Plugin
Inside Jenkins:

Click Manage Jenkins.

Select Plugins.

Open Available plugins.

Search HTML Publisher.

Install the plugin.

Step 6: Create Pipeline Job
Click New Item.

Enter name: karunya-site-pipeline.

Select Pipeline.

Click OK.

Scroll to Pipeline.

Select Pipeline script under Definition.

Step 7: Paste Jenkins Pipeline Code

pipeline {
    agent any

    stages {

        stage('Generate site') {
            steps {
                script {

                    def year = sh(
                        script: 'date +%Y',
                        returnStdout: true
                    ).trim()

                    sh 'rm -rf site'
                    sh 'mkdir -p site/assets'

                    writeFile file: 'site/index.html', text: """
<!DOCTYPE html>
<html>
<head>
    <title>Karunya University</title>
    <link rel="stylesheet" href="assets/style.css">
</head>

<body>

    <header>
        <h1>Karunya University</h1>
        <p class="tagline">Values - Knowledge - Service</p>
    </header>

    <div class="container">
        <h2>About Karunya University</h2>
        <p>
        Karunya Institute of Technology and Sciences
        is a leading centre for higher education in India.
        </p>
    </div>

    <footer>
        Copyright ${year} Karunya University -
        Generated by Jenkins
    </footer>

</body>
</html>
"""

                    writeFile file: 'site/assets/style.css', text: """
body {
    font-family: Arial, sans-serif;
    margin: 0;
    background: #f4f4f4;
}

header {
    background: #0b3d91;
    color: white;
    padding: 20px;
}

.tagline {
    font-size: 14px;
    opacity: 0.8;
}

.container {
    max-width: 800px;
    margin: 0 auto;
    padding: 20px;
}

.card {
    background: white;
    border: 1px solid #ddd;
    padding: 15px;
    margin: 15px 0;
    border-radius: 6px;
}

footer {
    text-align: center;
    font-size: 12px;
    color: #555;
    margin-top: 20px;
}
"""

                }
            }
        }

        stage('Publish site') {
            steps {
                publishHTML([
                    allowMissing: false,
                    alwaysLinkToLastBuild: true,
                    keepAll: true,
                    reportDir: 'site',
                    reportFiles: 'index.html',
                    reportName: 'Karunya University - Simple Site'
                ])
            }
        }
    }

    post {
        always {
            archiveArtifacts(
                artifacts: 'site/**',
                fingerprint: true
            )
        }
    }
}

Click Save.



Console Command to Activate CSS (Jenkins Script Console)
To allow Jenkins to render external CSS and stylesheets correctly for HTML reports, run this command in your Jenkins instance:

Go to your Jenkins dashboard.

Click on Manage Jenkins > Script Console.

Paste and run the following Groovy script:

Groovy

System.setProperty("hudson.model.DirectoryBrowserSupport.CSP", "")
Verification: The output box below the console should display result: null, indicating the property was successfully updated.

Step 8: Build and Run Pipeline
Open karunya-site-pipeline.

Click Build Now.

Wait for the build to finish.

Click the latest build number.

Click Karunya University - Simple Site.

Expected Result
Your Karunya University static website should appear inside Jenkins.

Step 9: Verify Build Artifacts
Inside the latest build page, check Build Artifacts.

Expected files:

site/
    index.html
    assets/
        style.css
Step 10: Check Jenkins Logs (Optional)
docker compose logs jenkins
Step 11: Stop Jenkins
docker compose down
Your Jenkins data will remain saved in the Docker volume.
